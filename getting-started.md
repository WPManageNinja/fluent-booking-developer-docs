# Getting Started

Welcome to the Fluent Booking Developer Documentation. This guide is designed to help you build powerful integrations and extend the functionality of Fluent Booking.

## Overview

Fluent Booking provides a robust set of tools for developers:

- **REST API**: Create, read, update, and delete data programmatically.
- **Hooks**: Hook into various events and modify data on the fly (Documentation coming soon).
- **Database Access**: Direct access to the database schema for advanced queries (Documentation coming soon).

## Prerequisites

To get started, you will need:

- A working installation of WordPress.
- Fluent Booking (and Fluent Booking Pro for advanced features) installed and activated.
- Basic knowledge of REST APIs and WordPress development.
