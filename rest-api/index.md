# REST API Overview

The Fluent Booking REST API allows you to interact with the Fluent Booking system programmatically. All API endpoints are prefixed with `/wp-json/fluent-booking/v2/`.

## Key Features

- **Standard REST Architecture**: Uses standard HTTP verbs (GET, POST, PUT, DELETE).
- **JSON Format**: All requests and responses are in JSON format.
- **Secure Authentication**: Requires Basic Authentication for all private endpoints.

## Base URL

```
https://yoursite.com/wp-json/fluent-booking/v2/
```

> [!NOTE]
> Replace `yoursite.com` with your actual website domain.
